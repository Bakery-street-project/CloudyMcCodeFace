# Contributing to CloudyMcCodeFace

This project is proprietary (see [LICENSE](LICENSE)); contributions require permission from the maintainers.

1. Create a branch: `git checkout -b feature/my-feature`
2. Commit your changes: `git commit -m 'feat: description'`
3. Push: `git push origin feature/my-feature`
4. Open a Pull Request

Be respectful in all project spaces.
